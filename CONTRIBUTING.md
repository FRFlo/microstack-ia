# Contribuer

Les signalements et propositions sont les bienvenus dans les issues du dépôt. Décrivez le besoin, les étapes de reproduction et l'environnement, sans inclure de secrets ni de données confidentielles.

Pour proposer une modification, ouvrez une pull request expliquant son objectif et les vérifications effectuées. Les contributions sont soumises sous la licence Apache 2.0 du projet.
